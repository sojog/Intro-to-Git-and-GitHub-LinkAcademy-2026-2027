Pentru a vedea versiunea de git instalată
# git --version  

Pentru a clona un repo de git
# git clone LINKUL_RESPECTIV
Exemplu:
### git clone https://github.com/sojog/Intro-to-Git-and-GitHub-LinkAcademy-2026-2027.git

INSTRUCTIUNI DE STATUS
Pentru a vedea statusul fisierelor modificate
# git status

Pentru a vedea commit-urile
# git log

Pentru a face un commit (fisiere se adauga intr-o noua stare stage)
# git add .
sau pentru a adauga un fisier anume 
# git add NUMELE_FISIERELOR

Pentru a crea un commit 
# git commit -m "Mesajul commitului"
Versiunea mai lunga
# git commit --message "Mesajul commitului"

Pentru a trimite commit-ul pe server
# git push
